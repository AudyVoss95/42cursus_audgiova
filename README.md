# 42 Cursus — Software Engineering Projects 🚀

Repository containing the core projects developed during the Software Engineering curriculum at **42 School**. Focus on low-level C programming, algorithm optimization, Unix environment, and strict code compliance (Norminette).

---

## 📌 Projects Index

| Project | Language | Description | Key Concepts |
| :--- | :---: | :--- | :--- |
| **libft** | `C` | Custom C standard library re-implementation. | Memory allocation, pointers, string handling, linked lists. |
| **ft_printf** | `C` | Custom implementation of the standard `printf` function. | Variadic functions (`va_list`), format specifiers, type conversion. |
| **get_next_line** | `C` | Function that reads and returns a line from a file descriptor. | Static variables, dynamic buffer management, file descriptors, memory leaks prevention. |
| **ft_push_swap** | `C` | Highly efficient sorting algorithm to sort data on a stack with limited operations. | Algorithmic complexity ($O(n \log n)$), stack manipulation, sorting benchmarks, input parsing. |

---

## 🛠️ Tech Stack & Standards
- **Language:** C (C99 / C11)
- **Compiler:** `gcc` / `clang` with flags `-Wall -Wextra -Werror`
- **Build System:** `Makefile` (all, clean, fclean, re)
- **Tools & Environment:** Linux / Unix CLI, Valgrind, Bash / Zsh
- **Coding Standard:** 42 Norminette compliance

---

## 💻 How to Build and Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/AudyVoss95/42cursus_audgiova.git](https://github.com/AudyVoss95/42cursus_audgiova.git)
   cd 42cursus_audgiova
   ```


2. **Navigate to a specific project and compile:**
* **Libft / ft_printf:**
   ```bash
   cd Libft
   make

   ```


* **ft_push_swap:**
   ```bash
   cd ft_push_swap
   make
   ./push_swap 2 1 3 6 5 8

   ```
